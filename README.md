```text

                         │
                         ▼
              ┌─────────────────────┐
              │ ANALYTICS / REPORTS │
              └─────────────────────┘
```

AETHER is the clearest expression of my interest in **AI evaluation as a system**, not merely a metric in a notebook.

The project combines a FastAPI backend, evaluation workers, PostgreSQL/Alembic infrastructure, a Next.js frontend and D3-based analytics, with unified LLM access through LiteLLM. It uses a dark-first glassmorphic design system with reusable UI components and analytical charts.

### AETHER mental model

```text

└── evaluation rules

        ├──── latency
        ├──── correctness
        ├──── quality
        ├──── safety
        └──── rubric / judge score
        │
        ▼
EVALUATION
        │
        ▼
OBSERVABILITY
        │
        ▼
UNDERSTANDING
```

### Why it matters

> A model is only as useful as our ability to understand its behavior.

### [`Logistic-Regression`](https://github.com/MAqeel151214/Logistic-Regression)

It focuses on:

```text
Perceptron learning
        ↓
Sigmoid transformation
        ↓
Decision boundaries
        ↓
Gradient descent
        ↓
Evaluation
        ↓
Confusion matrices
```

The notebooks explicitly explore weight updates and decision boundaries rather than treating logistic regression as a black-box function call.
